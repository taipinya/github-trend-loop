### 2. boykopovar/AnyPS5
- URL：https://github.com/boykopovar/AnyPS5

#### 项目简介
AnyPS5 属于**二进制移植与系统兼容层**领域，目标是把 PS5 可执行文件自动移植到 Linux 和 Windows。从 README 摘要看，它的核心是一个 relinker，把可执行文件转换成目标系统的原生格式，并实现了一套适用于动态链接的系统 prx 库。它明确强调“No emulation or separate runtime process”，即不走模拟器路线，而是通过重链接 + 动态库替换让程序直接在目标系统上运行。topic 中出现 SPIR-V、Vulkan，暗示图形层可能通过着色器翻译或 Vulkan 后端来承接。

#### 为什么值得关注
- stars 7220、forks 545，subscribers 104，对于一个技术门槛较高的移植工具来说，关注度不低。
- topic 组合（anyps5、dynamic-library、game-porting、ps5、ps5-tools、spir-v、vulkan）非常具体，能直接看出技术栈方向：动态库、图形 API 翻译。
- 最近 push 为 2026-10-07，维护活跃；open_issues 196，说明兼容性问题多，符合这类项目的典型特征。

#### README 摘要
中文说明：README 结构偏工程文档，先说明工具用途（自动移植可执行文件到 Linux/Windows），然后指向 core/relinker（重链接器）和 core/libs/prx（系统 prx 库实现），并给出 Usage、Build instructions、Technical debt、code style conventions、contributing 等文档入口。还包含 libraries 和 shaders 的状态徽章，说明项目对库覆盖率和着色器支持有量化跟踪。

摘要线索：描述为 “Tool for automatic executables porting to Linux and Windows”，包含 relinker 和 system prx libraries，强调 “No emulation or separate runtime process”；文档入口包括 docs/user/USAGE.md、docs/dev/BUILD.md、docs/dev/TechnicalDebt.md、docs/dev/CONVENTIONS.md、CONTRIBUTING.md。
