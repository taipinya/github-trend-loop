### 1. mattpocock/skills

- URL：https://github.com/mattpocock/skills

#### 项目简介

这个项目属于 AI Agent 技能集配置领域。作者是一名有影响力的 TypeScript/前端教育者，他在自己的 `.agents` 目录中维护了一套用于日常真实工程开发的 Agent 技能。技术原理上，这些技能可能以 `SKILL.md` 或可执行的 Shell 脚本来定义，让 LLM Agent 在编码任务中按需调用外部命令、执行分析流程，从而完成代码修改、测试运行、依赖处理等操作。简单说，它是“让 Agent 学会干活”的具体工程配置。

#### 适合谁关注

适合正在使用或准备使用 AI 编码助手的个人开发者，尤其是想提高 Agent 自动化程度的同学。也适合对“工具调用、上下文工程、技能编排”感兴趣的研究型工程实践者，因为它提供的是可复制的工程化范式，而非抽象概念。

#### 应用场景示例

- 代码审查：Agent 自动拉取 diff，执行静态检查，并按照仓库规范输出 review 意见。
